Transparency

Privacy, data flow and support

Local by default

Core audio processing, local transcription and local model integrations run on this Mac. The desktop service listens on 127.0.0.1.

Network use is contextual

Text leaves the device only when an online TTS option is selected. Audio chunks are sent across the LAN only when you connect and use a trusted edge worker.

Support with care

GitHub Issues is the public support channel. Do not attach private recordings, personal data, access tokens or unreviewed diagnostic logs.
