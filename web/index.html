Transparency

Where each function runs.

AudioEnhancerMAX separates local processing, optional local helper software, trusted-LAN workers, and external services so each boundary can be understood and controlled.

On this Mac

Uploads, DSP, deterministic Smart Enhance analysis, local Whisper transcription, EDL history, reports, and interface assets remain on the host Mac.

Default path

Local helper process

Optional Ollama/Gemma editorial assistance runs through a local process. It may draft text suggestions, but it never chooses DSP parameters.

User controlled

Personal voice runtime

The source supports named, consent-based profiles through the separately evolving MakeMyVoice project. Voice samples and generated audio stay local.

Development head · local Metal

Trusted local network

Selected DSP chunks can reach Android workers only when trusted-LAN processing is enabled and a worker is connected by the user.

Separate boundary

Optional external service

Edge Neural TTS sends only the submitted text to Microsoft. A persisted privacy control can disable this path independently of local features.

Processing toolkit

Audio modules
you can inspect.

Core DSP stays deterministic. Local model inference, optional local editorial assistance, optional external TTS, and optional LAN workers are labeled as distinct execution boundaries.

Noise Removal

DeepFilterNet v3 when installed, with spectral-gating fallback and wet/dry mixing. The active engine is reported by the runtime capability registry.

Conditional engine

Filler Word Removal

Whisper-based timestamps help identify common filler patterns such as "uhm", "eh", and "basically" for reviewable cleanup.

Whisper AI

Studio Sound v2.0

Voice-focused chain with warmth at 150Hz, presence around 4kHz, de-essing, gentle 2:1 compression, and limiting.

Pedalboard

Metal GPU Acceleration

Compatible model paths can use Apple Metal through PyTorch MPS. Whisper uses ARM-optimized CTranslate2; accelerator use depends on the active operation.

Operation dependent

Optional Editorial Assistant

When Ollama/Gemma is enabled locally, it can provide explicitly requested editorial prose. Deterministic signal analysis remains responsible for DSP recommendations.

Local optional helper

Edge Cluster Computing

Experimental Android workers can run selected DSP tasks on a user-enabled trusted LAN. Pairing, authentication, and workload limits are next-release hardening gates.

Experimental boundary

Music Preservation

When Demucs and its assets are installed, vocals can be separated, processed, and remixed with background music. This engine is not universal across distributions.

Demucs · conditional

Real-time Monitoring

The monitor separates system CPU from app-process CPU and labels GPU, ANE, power, and temperature values as measured, estimated, or unavailable.

Truthful telemetry · dev head

AI Transcription

Word-level timestamps export to SRT, VTT, and JSON. Speaker diarization uses pyannote when available; the heuristic fallback is not presented as production-grade diarization.

Whisper · conditional diarization

Personal Voice Studio

Create or link a named voice profile, save synthesis defaults, re-enrol it, and use a validated MakeMyVoice engine. Advanced training and model promotion remain in MakeMyVoice.
