How to clean up podcast audio locally on Mac

A practical path from the original recording to a reviewed export, with noise reduction, transcript edits and clear processing boundaries.

By Fabrizio Degni · October 23, 2026

What this workflow covers

AudioEnhancerMAX is a free, open-source audio editor for Apple Silicon Macs. It combines local speech cleanup, transcript-based editing and export checks. Use it when you want to review the changes to a recording and keep the source intact. The direct release requires macOS 13 or later; speech models may download on first use.

1. Start with a short, representative recording

Import a copy of your source and listen before processing it. Pick a passage containing speech, a quiet pause and the noise you want to reduce. Notice whether the problem is steady background noise, uneven level, repeated filler words or an unwanted section. These call for different decisions. A clipped or badly distorted source may remain damaged after processing.

Keep the unprocessed recording. AudioEnhancerMAX preserves the uploaded source through its non-destructive edit history, but an independent backup is useful when you compare versions or move projects.

2. Reduce noise without removing the voice

Start with the Conservative Smart Enhance option and inspect its explanation. Smart Enhance uses measured signal characteristics to recommend DSP settings. The optional local Ollama editorial assistant can suggest prose; it does not choose the DSP parameters.

Noise removal uses DeepFilterNet when installed, with a spectral-gating fallback. Check the reported active engine before comparing results. Listen for softened consonants, a metallic voice or pumping background noise. If these appear, reduce processing or adjust the wet/dry mix, then compare the same passage again. More processing is not automatically a better recording.

3. Review the transcript before cutting speech

Generate a local Whisper transcript and compare important words with the recording. Automatic transcription and filler detection can be wrong. Select the proposed words or passage in the Precision Speech Editor, review the suggested cut or mute, then apply only the changes you accept. Undo and redo allow you to revisit an edit.

A pause or repetition may carry meaning. Keep it when removing it would change the speaker's intent. Render the accepted edit decisions before treating the output as the version you intend to deliver. A later transcript change does not prove that an earlier render used the new text.

4. Choose an export target and inspect the result

Select the delivery profile that matches your destination: podcast, video, audiobook, lossless archive or source-quality master. Review format, sample rate and level choices before exporting. The Delivery Compliance Lab reports integrated loudness, estimated true peak, clipping and sample-rate checks. Read the individual results and warnings.

These checks are workflow guidance. They do not certify acceptance by a hosting platform or audiobook distributor. Check your destination's current requirements and listen to the exported file itself. A loudness check cannot tell you whether the pacing is natural or a word was cut incorrectly.

5. Keep the evidence with the delivered file

Export a Project Capsule when you need to retain the processed audio and the available report, transcript, edit decisions and review evidence. Version 3.8.3 ties capsule evidence to the selected render and hashes the actual archived bytes. The original source audio is excluded by default; inspect the package before sharing it.

Hashes help check file integrity. They do not prove speaker consent, transcription accuracy or good sound. The final decision still depends on listening and on the permission you have to use the recording.

Which features need a network?

PathBoundary
Core DSP and transcriptionRun on the Mac. Models may need an initial download.

Android workersOptional, experimental processing on a trusted local network.

Review the privacy boundaries and your settings before using a confidential recording. “Local-first” does not mean every optional feature is offline.

When this app fits

Consider AudioEnhancerMAX for spoken recordings where local processing, reviewed edits and an inspectable export trail matter. First check the hardware requirements and download FAQ. If your workflow needs an Intel Mac package, a Windows installer or guaranteed support for a particular optional model, do not assume that the Apple Silicon DMG provides it.

Personal Voice Studio and experimental worker features have separate development boundaries. Use the project status and the notes for your exact package to decide whether a feature is available.

Sources and verification scope

This guide describes the public 3.8.3 workflow. It is not an independent listening test or a promise of perceptual improvement. Check the 3.8.3 release notes, exact packaged-build evidence and reviewable audio decisions. For a reproducible problem, follow the support instructions.
