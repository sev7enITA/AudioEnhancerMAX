What is in the BETA

  • A waveform-centred workspace for import and cleanup, listening and editing, then export.
  • Same-excerpt spectral cleanup preview, local analysis, suggested settings, and recent files.
  • Original/revision A/B with playhead mapping for speech-editor cuts, and optional listening-only level matching.
  • Transcript-linked selection and reviewable cut or mute proposals, with undo and redo.
  • Format-specific delivery checks, processing report and Project Capsule tied to the completed result.

Apple Silicon (arm64), macOS 13 or later. Developer ID signed, Apple notarized and stapled.

Quit AudioEnhancerMAX before replacing the app. Keep the earlier stable DMG available if you need to return to 3.9.0.

Playhead mapping covers speech-editor cuts. Other Enhance operations that change duration may use independent playheads. Speech analysis requires the local model. The companion adds filtered import, two-way Wi-Fi pairing and About links for privacy and support. See the exact scope in the build verification record.

With a configured signing identity, the app can embed C2PA Content Credentials in a copy of a WAV, MP3 or FLAC export. The manifest records the revision and the SHA-256 of its downloadable processing report. Audio watermarking is a separate action that changes the audio samples.

The direct Mac build supports a non-exportable Keychain signing key and RFC 3161 timestamping with a configured service. Apple's Developer ID and notarization apply to the app package. A C2PA validator assesses the audio signature and trust for the media separately.

Local audio, reviewable decisions and Music brief

What is new

Music brief offers six original presets, editable styles and arrangement directions, a separate lyrics field and JSON export that retains source inputs and the edited prompt. The core builder works without a model or network. Optional Ollama suggestions require an installed local model and permission; they remain separate until reviewed and appended.

This assistant prepares text, not generated music. It does not call MiniMax. Drafts remain in the current session, so copy or export before closing; JSON re-import is not included.

A practical first look

  1. Install and complete the local readiness screen.
  2. Open Music brief, apply Podcast intro, write a short description, build and edit the prompt, then export JSON.
  3. Import a recording you own. Apply conservative cleanup, compare original and output and export WAV, MP3 or FLAC.
  4. Review the processing report and export a Project Capsule. Try transcription once a model is available and review proposed speech edits before rendering.

What the evidence does and does not show

Automated regressions, packaged workflow checks, signature verification and dependency checks are documented with the release. They do not establish every supported macOS configuration, first-time model acquisition, subjective listening quality or transcription accuracy. Loudness guidance and hashes support review, not certification.
