01 / Contact

Start with the right channel

Bug reports and support requests are tracked in the public GitHub repository. Search existing tickets first, then open a new issue with the smallest amount of information needed to reproduce the problem.

Public support ticket

Use GitHub Issues for installation problems, unexpected behavior, feature questions and documentation gaps. Tickets and attachments are public.

Open a support ticket Search existing tickets Release downloads
Do not publish sensitive material.

Do not attach confidential recordings, transcripts, credentials, personal identifiers or private system logs to a public ticket. Describe the issue using a synthetic or redacted sample whenever possible.

02 / Good report

What to include

  1. AudioEnhancerMAX version and distribution channel, such as Mac App Store, GitHub DMG or source installation.
  2. macOS version, Mac model and chip family.
  3. Exact steps that led to the problem and what you expected instead.
  4. Selected processing modules, output format and whether an optional integration was enabled.
  5. The complete error message, with usernames, file paths and personal data redacted.
  6. Whether the same issue occurs with a short, non-confidential test recording.

For audio quality reports, describe the source conditions and the selected parameters. Quality depends on the recording, settings and enabled engines, so a result cannot be assessed from the feature name alone.

03 / Quick checks

Resolve common problems first

The app does not start Restart the app and review the first-run readiness result. A missing mandatory bundled component should be reported as a packaging defect.
A file will not import Confirm that the file is within the 500 MB application limit and uses WAV, MP3, MP4, FLAC, OGG, M4A, AAC or WMA.
Processing sounds too strong Reduce noise strength or wet/dry balance, disable modules one at a time and compare against the preserved original.
Smart Mode is unavailable Core DSP remains usable. Ollama and a compatible local Gemma model are optional and are not prerequisites for the core workflow.
A TTS voice cannot connect Local Kokoro and network-dependent Edge Neural voices have different requirements. Check which engine is selected before troubleshooting.
A phone worker is not found Verify both devices are on a trusted local network. Worker discovery and audio offload are optional and require local network access.

More detailed procedures are maintained in the troubleshooting guide.

04 / Compatibility

System requirements

The packaged macOS release targets Apple Silicon and macOS 13 or later. Storage, memory and optional engine requirements vary with file duration, processing modules and model selection.

The Mac App Store package is expected to include all components required for its core workflow. Ollama, compatible local models, trusted LAN workers and network TTS voices remain optional capabilities and must not be required to open or use the core application.

Distribution packages are not interchangeable.

The Mac App Store build, GitHub DMG and source installation can have different sandbox, signing and dependency boundaries. Always identify the distribution when requesting support.

05 / Safe support

Support and your data

AudioEnhancerMAX does not automatically upload diagnostics to the maintainer. Support information is provided only when you choose to create a ticket or contact a third-party platform.

  • Share text logs only after reviewing and redacting local paths and identifiers.
  • Use generated test audio instead of a private recording.
  • Do not share model prompts or transcripts that contain confidential content.
  • GitHub processes ticket content under its own terms and privacy policy.

For privacy-related requests, open a minimal ticket labeled as a privacy request and do not include the underlying personal data. The maintainer can then identify an appropriate follow-up channel.

06 / Scope

What open-source support means

Support is provided on a reasonable-effort basis by the project maintainer and contributors. No guaranteed response or resolution time is offered unless a separate written agreement exists.

AudioEnhancerMAX is provided under the MIT License without warranty. Support can help diagnose behavior, but it cannot guarantee restoration of damaged source media, transcript accuracy, compliance outcomes or suitability for a specific professional decision.
