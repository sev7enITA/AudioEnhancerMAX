AudioEnhancerMAX 3.9: release evidence.

Verified processing revisions, exact-format delivery evidence, and an explicit macOS distribution status.

Audited October 27, 2026 Public release 3.9.0 source Signed package 3.9.0 / build 3.9.2 notarized
01 / Distribution

Source release and notarized macOS package

The latest stable direct release is 3.9.0/build 3.9.2, Developer ID signed, Apple notarized and stapled. Music brief moves into stable with six original presets, editable text prompts and JSON export. Updated dependencies accompany the existing audio workflow. Downloads and requirements.

Stable preserves the existing stable data folder. Earlier Experimental 1 remains a separate installation; no automatic experimental-data migration occurs. Previous stable 3.8.3 is retained for rollback. This direct release does not establish Mac App Store approval.

02 / Implemented

One completed revision through delivery

  • DSP checkpoints verify source bytes, requested and effective settings, step order, application build and runtime versions. Incompatible or corrupt work restarts cleanly.
  • Every processed or speech-edited result has a distinct revision. Cached exports cannot be reused for another revision.
  • WAV, MP3 and FLAC delivery checks record the exact exported file's SHA-256 and format. Speech-edit reviews and capsules follow the selected operation.
  • New runs clear the previous UI result; late responses cannot replace evidence for another revision.
03 / Verification

135 Python tests, 11 subtests and 19 JavaScript tests

Regression checks cover audio processing and result identity, local transcription contracts, privacy recovery, exact capsule bytes, stable upgrade data separation, Music brief validation and frontend stale-result handling. The final build environment passed dependency integrity checks and pip-audit reported no known vulnerabilities on 27 October 2026 after dependency updates.

See the exact package verification record for native startup, processing, transcription, export and Music brief checks on the release artifact. Package checks do not establish every macOS combination, first-time model acquisition or perceptual audio quality.

04 / Boundaries

Local runtime and optional engines

Core processing and Music brief construction run locally. Music brief is text-only and drafts are session-only; copy or export before closing. Bundled PyAV codecs support the packaged core workflow without external FFmpeg. Direct macOS transcription models are runtime-managed; the App Store packaging path is separate. MakeMyVoice personal-voice synthesis needs an installed compatible runtime and explicit voice-owner consent. Optional external TTS and trusted-LAN processing remain independently controlled.

Model-dependent and LAN paths do not claim resumable identity. Android debug workers remain experimental and disabled by default. Keep one backend worker per data directory. Completed revisions are retained locally, so disk usage grows until the user removes unneeded artifacts.
