02 / Implemented

One completed revision through delivery

  • DSP checkpoints verify source bytes, requested and effective settings, step order, application build and runtime versions. Incompatible or corrupt work restarts cleanly.
  • Every processed or speech-edited result has a distinct revision. Cached exports cannot be reused for another revision.
  • WAV, MP3 and FLAC delivery checks record the exact exported file's SHA-256 and format. Speech-edit reviews and capsules follow the selected operation.
  • New runs clear the previous UI result; late responses cannot replace evidence for another revision.
03 / Verification

79 Python tests and 4 JavaScript tests passed

Thirteen new audio/API cases cover interrupted processing, resumption, changed source/settings/build, corrupt checkpoints, three-run deterministic repeatability, cached conversions, stereo preservation, format changes, exact-export hash binding, speech-edit capsules and duplicate-job rejection. Four JavaScript cases exercise stale responses and disabled result actions.

Four additional transcription regressions cover normal and streaming paths and their fallback behavior. On 18 October the corrected direct DMG passed packaged runtime checks for processing, normal and streaming transcription, speech-edit apply/undo/redo/render, WAV/MP3/FLAC exports and capsule hashes. The test used the developer-owned review sample and an existing local Medium model cache with Hugging Face and Transformers offline flags. First-time model acquisition and audio quality are not established by this test. TestFlight screenshots show the separate App Store build 3.8.3, whose model packaging differs from the direct download.

The installed build environment passed dependency integrity checks and pip-audit reported no known vulnerabilities on 15 October 2026. These checks are scoped evidence, not a general security or audio-quality certification.

04 / Boundaries

Local runtime and optional engines

Core processing runs locally. Direct macOS transcription models are runtime-managed; the App Store packaging path is separate. MakeMyVoice personal-voice synthesis needs an installed compatible runtime and explicit voice-owner consent. Optional external TTS and trusted-LAN processing remain independently controlled.

Model-dependent and LAN paths do not claim resumable identity. Android debug workers remain experimental and disabled by default. Keep one backend worker per data directory. Completed revisions are retained locally, so disk usage grows until the user removes unneeded artifacts.
