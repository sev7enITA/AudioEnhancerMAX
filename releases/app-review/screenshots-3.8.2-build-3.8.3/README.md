Captured on 16 October 2026 from the Apple TestFlight installation on a physical MacBook Pro (Mac15,9), M3 Max, macOS 27.2 (26B5112a). The app uses its English interface. The sample contains developer-created speech only.

1. Review Deck after processing and a reviewed speech edit.

Each original window capture was centered to a 16:10 aspect ratio by removing five pixels of window border from the top and bottom, then resized to 2880 x 1800 PNG. No UI elements were composited or altered. See manifest.json for capture provenance and SHA-256 values. The screenshots are prepared locally; this directory alone does not establish an upload to the Store listing.
