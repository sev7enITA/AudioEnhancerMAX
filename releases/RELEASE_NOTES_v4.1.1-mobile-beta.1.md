# AudioEnhancerMAX Companion 4.1.1 BETA

**About → Updates** checks for new companion builds. Direct distribution is limited to the official AudioEnhancerMAX GitHub and SourceForge repositories. Choose one in the app. The source setting stays on the device.

- **Android 4.1.1 build 17** ships as a signed direct BETA APK. The updater checks signed release data and then the downloaded APK’s SHA-256, size, app ID, build and signing certificate. Save the verified APK and confirm the update through Android.
- **iOS 4.1.1 build 13** ships as an unsigned Xcode archive and source. The developer app checks signed release data and verifies the archive before saving it. Installation on iOS requires Apple-authorized distribution or developer signing and provisioning.
- **Store editions** keep updates within their own store. Public companion listings on Google Play and the App Store are pending.
