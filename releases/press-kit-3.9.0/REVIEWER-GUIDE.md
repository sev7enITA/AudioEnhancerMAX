# Reviewer guide and factual boundaries

Product: AudioEnhancerMAX 3.9.0, build 3.9.2. Developer: Fabrizio Degni. Free direct download, MIT source. Apple Silicon, macOS 13+. English application interface. No account or subscription for the core workflow.

## A five-minute first look

1. Install the official DMG, replacing an older stable app only after quitting it. Launch and complete the local readiness screen.
2. Open Music brief. Choose Podcast intro, apply its directions and describe an instrumental opening for a spoken-word show. Build the brief, edit one sentence and export JSON. Check that the current prompt, original caption and separate lyrics remain distinguishable.
3. Import a short recording you own or the included developer-created review sample. Apply conservative noise reduction, EQ or loudness processing. Listen to original and result at comparable levels.
4. Export WAV, MP3 or FLAC. Open the processing report and export a Project Capsule. Hashes record file identity; they are not a quality score.
5. For transcription, allow the initial local model download or use a model already cached. Review words and timestamps. In Precision Speech Editor, inspect a proposed edit, apply it deliberately and compare the rendered result; originals remain preserved.

Ollama suggestions, external TTS and trusted LAN workers are optional. Do not enable them just to complete the core evaluation. Ollama requires a separately installed local model. No music-generation model is bundled. Draft persistence and JSON re-import are not included.
