# AudioEnhancerMAX Companion 4.1.2 BETA

| Platform | Build and package |
| --- | --- |
| Android | Build 19. Signed APK for direct QA installation. |
| iOS | Build 14. Unsigned Xcode developer archive. Installation requires the appropriate Apple signing and provisioning. |

- Verify adds a media metadata inspector. It shows available container and track properties, native audio and video tags, and EXIF for supported embedded artwork. Private tag values stay on the device by default.
- Studio explains which formats can be edited and where codec availability depends on the phone. The app checks the file when importing it and preserves the original.
- A welcome screen introduces the current build and links to release details and references. About shows the installed build and update channel.
- About → Updates checks the authorized installation channel. For Android direct distribution, verification covers the signed release metadata, the APK digest and the signing identity. iOS distribution follows Apple signing and installation rules.
