# AudioEnhancerMAX 4.1.2 BETA for Mac

Build 4.1.4 is a direct download for Apple Silicon Macs running macOS 13 or later.

- The refreshed desktop layout makes the primary actions easier to find. It gives the signal view and the Text to Speech controls more space and uses larger labels and icons.
- The native workspace picker filters supported media. Import and initial analysis leave the source unchanged. The workspace shows suggested settings, the selected preset and when a revision has been rendered.
- Workspace history records actions for the imported file and its revisions. A signed export links to the processing report by SHA-256 and includes observed processing evidence. The original download remains available.
- The monitor identifies the chip and queries the Mac running the app. Optional acceleration and telemetry depend on the available runtime. Metrics are shown only when they are measured, and Neural Engine power is shown in watts. Time estimates reflect the evidence available.
- Local audio cleanup, bundled codecs and verification run on the host. Optional engines, models and C2PA signing identities have their own setup.

The DMG is signed with Apple Developer ID and notarized. C2PA signing requires an identity configured by the operator. The included verification evidence uses a test identity. C2PA conformance and production signer trust have separate approval and issuance processes.
