# AudioEnhancerMAX 3.7.0 — Press Kit Copy

## One-line description

AudioEnhancerMAX 3.7 is a local-first Mac audio production workspace that makes enhancement and speech-editing decisions reviewable from diagnosis to export.

## Short description

AudioEnhancerMAX combines deterministic audio diagnosis, local processing, packaged Faster-Whisper transcription, a non-destructive transcript-linked editor, explicit delivery profiles, rule-level delivery guidance, blind A/B listening, and checksum-backed Project Capsules in a native macOS window. Optional external, local Ollama and trusted-LAN paths are independently controlled and disclosed.

## Boilerplate

AudioEnhancerMAX is an MIT-licensed audio production project created by Fabrizio Degni for podcasters, interviewers, journalists, educators, researchers, voice creators, and developers who value local processing, user review, and transparent execution boundaries. Version 3.7 introduces deterministic Smart Enhance profiles, the Precision Speech Editor, five fixed delivery profiles, the Delivery Compliance Lab, checksum-backed evidence export, runtime privacy controls, and a native Apple Silicon Mac experience.

## Launch announcement

**AudioEnhancerMAX 3.7 makes local audio enhancement reviewable**

AudioEnhancerMAX 3.7 advances the open-source audio workspace from tool selection to an evidence-led production flow. Smart Enhance now measures common recording risks locally and proposes deterministic settings. The new Precision Speech Editor connects local word timestamps to reversible cut and mute decisions, while five delivery profiles make format and loudness choices explicit. A per-job report records the selected profile, actual engines, warnings, privacy state and approved edits. The Delivery Compliance Lab measures loudness, estimated true peak, clipping and sample rate against visible workflow targets. A randomized blind A/B review avoids disclosing the source before the choice, while the Project Capsule exports SHA-256 evidence with the original audio excluded by default.

On macOS, the application runs in an AudioEnhancerMAX-owned native window and starts a private loopback service that ends with the app. The Mac App Store package includes the local Faster-Whisper Medium model and embedded media libraries. Optional Microsoft TTS, separate local Ollama assistance and trusted-LAN workers remain disclosed and independently controlled.

The release is designed around a simple principle: automation may propose, but the user reviews what becomes part of the output.
