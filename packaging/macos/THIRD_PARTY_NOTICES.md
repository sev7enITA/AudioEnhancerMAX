# AudioEnhancerMAX third-party notices

AudioEnhancerMAX includes open-source components. The corresponding license
texts are shipped in the `licenses` directory inside the application bundle.

## PyAV and FFmpeg libraries

PyAV provides Python bindings for FFmpeg and is distributed under the
three-clause BSD license. The FFmpeg shared libraries bundled by the PyAV wheel
identify themselves as LGPL version 3 or later. Their license text is included
as `COPYING.LGPLv3`.

- PyAV: https://github.com/PyAV-Org/PyAV
- FFmpeg: https://ffmpeg.org/
- FFmpeg source: https://ffmpeg.org/download.html

The libraries remain dynamically linked files inside the application bundle.
AudioEnhancerMAX does not prevent replacement or reverse engineering of these
libraries for the purpose of debugging modifications, as permitted by the
applicable license.

## Faster-Whisper and bundled Whisper Medium model

The Faster-Whisper software and the `Systran/faster-whisper-medium` model are
distributed under the MIT license. The model is a CTranslate2 conversion of
OpenAI's Whisper Medium model and is stored entirely inside this application;
the Mac App Store build does not download model files at runtime.

- Faster-Whisper: https://github.com/SYSTRAN/faster-whisper
- Model card: https://huggingface.co/Systran/faster-whisper-medium
- Original Whisper project: https://github.com/openai/whisper

Additional Python package license metadata is preserved in the bundled
distribution metadata generated by PyInstaller.
