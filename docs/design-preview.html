05 / BEHAVIOR

Designed for trust.

The interface earns confidence through visible boundaries and reversible actions, not visual spectacle.

01

Local is explicit

State where processing occurs at the decision point, before a file or text can leave the Mac.

02

Focus is visible

Every action works with a keyboard and carries a high-contrast cyan focus outline.

03

Motion has meaning

Animation explains progress or transition and yields completely to reduced-motion preferences.
